# Golden Catering

A Next.js App Router site for Golden Catering, an Indian and Pakistani catering business led by Chef Adrees Athwal in Brampton, Ontario.

Run `npm install` and `npm run dev` for local development. Run `npm run build` to check the production build.

Set `NEXT_PUBLIC_CATERING_EMAIL` in `.env.local` for development or in the Vercel project environment for deployment. Rebuild after changing the setting. The inquiry form prepares a message visitors can copy and, when an email is configured, open in their mail app.

The sample menu and stock photos are editable in `app/interactive.jsx` and `app/page.jsx`.
